# Beyond Grades

Public GitHub Pages website for Beyond Grades.

Live URL: https://ij-roy.github.io/beyond-grades/

The site is intentionally static HTML, CSS, and JavaScript so it can be served directly from the repository's GitHub Pages project path. Legal and support pages are kept as directory `index.html` files for clean URLs:

- `/privacy-policy/`
- `/account-deletion/`
- `/terms-of-service/`
- `/contact/`

The design uses the Beyond Grades app palette and the exact app logo from the Android project. `robots.txt` and `sitemap.xml` are included for search discovery.
